世界模型正在被迫写清三份合同

过去十天最重要的变化不是新架构数量，而是三个长期被混在一起的问题开始拆开：物理 grounding 规定状态必须受什么现实约束，反事实证据规定一个结论凭什么属于“这次事件”，图结构则规定模型究竟相信哪些关系。世界模型从生成器走向系统，关键资产将是状态、证据与关系的合同。

本周发生了什么

Grounding 从“更真实”变成接口约束

Actionable Simulators 把物理、领域规则、结构化状态与自我演化放进系统合同。它提醒团队：世界模型不是一个视频端点，而是受约束的状态转移、接口与校验闭环。

Counterfactual 从控制信号变成证据问题

驾驶反事实框架区分“另一动作下的合理未来”与“同一个已发生世界的替代结果”。没有先用事实结果做 abduction，动作可控生成仍不能回答 episode-specific counterfactual。

Graph 从组件变成关系合同

Graph World Models 用 Connector、Simulator、Reasoner 统一空间、物理与逻辑 relational inductive bias。图的价值取决于边的真值、生命周期和可验证性，而不是是否用了 GNN。

本周最重要的连接：状态没有 grounding，事实没有 provenance，关系没有验证，模型即使能生成连贯未来，也无法成为可依赖的模拟、审计或决策基础设施。

哪些假设变弱了

“可控生成就是反事实”

替换动作只能定义 intervention query；要回答特定事件，还必须用事实结果锁定同一个世界，并声明剩余不可识别性。

“图结构天然可解释”

错误边可以比连续潜变量更有迷惑性：它看起来离散、清晰，却可能来自感知漂移、LLM 幻觉或相关性误判。

“物理先验自动带来泛化”

如果对象、边界、约束与观测接口不一致，先验只会把错误写得更稳定。泛化仍需 held-out 环境与外部校验。

“framework 写在标题里就有 field-level 价值”

本轮四个候选均是具体管线或系统。方法框架解决局部任务，不等于提供可跨方法复用的定义、taxonomy 或研究路线。

“最终成功率能定位模型问题”

成功率纠缠构图、转移、生成、规划器、shield 与回退逻辑；没有组件级证据就无法归因。

“更多数据能替代状态合同”

若团队没有定义哪些状态、关系和事实必须保存，增加视频或 rollout 只会扩大不可审计的数据湖。

机会正在变得更具体

关系 observability

为动态图提供边 provenance、置信度、版本、冲突、遗忘和回滚，连接机器人记忆、数字孪生与 Agent runtime。

Counterfactual evidence layer

保存事实延续、动作干预、传感器标定与生成区域来源，让离线安全复盘输出可审计候选，而不是单一炫酷视频。

Grounding validator

把物理守恒、几何可达、领域规则和语义约束做成独立校验器，并对无法验证的状态提供 uncertainty gate。

Graph-specific benchmark

分别评估 graph fidelity、关系转移、长时稳定性、分布移位和构建/更新/检索成本，补足任务成功率的归因盲区。

封闭场景的结构化孪生

仓储、设备、受约束流程和小规模对象交互的边真值可获得，是验证 GWM 产品价值的优先楔子。

Claim-contract tooling

把 forecast、intervention、counterfactual、policy evaluation 与 optimization 的输入、证据和拒答条件写进 API 与评测卡。

研究空白与可证伪假设

假设如何证伪价值
外部验证的动态图能在固定内存下提高长期任务成功率。固定存储与算力，对比静态图、只增图和可遗忘图在永久环境变化下的表现。决定 graph memory 是否具备部署优势。
事实 provenance 能显著提升反事实审计质量。让分析者在有/无区域级证据来源时判断同一批事故案例，比较错误结论与复核时间。验证 evidence layer 是否值得额外日志与推理成本。
概率关系转移比确定性 GWM 更能预测安全尾部。在多模态物理与分布移位场景比较校准、风险排序和闭环碰撞。决定图世界模型是否能支撑 assurance。
graph fidelity 能跨任务预测闭环收益。对多类 Connector/Simulator 模型同时测结构指标与下游结果，检查排序稳定性。可能形成跨子领域诊断协议。
独立 grounding validator 能降低 planner exploitation。让优化器主动搜索模型漏洞，比较共享模型判别器与外部规则/模拟器校验器的失效率。决定校验层是否能成为上线门禁。
