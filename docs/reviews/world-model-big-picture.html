世界模型大图景：从预测未来到治理可行动的模拟世界

2026 年的主线已经从“生成是否逼真”转向“一个模拟世界是否可交互、可验证、可迁移、可治理”。新加入的经济世界模型把边界进一步推到制度、信念和反身性：世界的规律不再总是固定外在法则，也可能被世界里的主体共同改写。

领域的四条主轴

定义与能力

用状态、动作、转移、因果、记忆和规划界定“世界模型”，避免把视频生成器、知识库和普通预测器混为一谈。

行动与交互

从被动预测走向闭环控制：模型必须接受意图或动作，保留跨时间一致性，并把未来表征反馈给策略。

验证与准入

逼真不是可信。评估逐渐从像素质量扩展到可控性、物理性、任务效用、失效边界和结论准入等级。

制度与反身性

经济世界模型带来新问题：主体信念塑造行动，聚合结果改变规则，规则又重写未来行为，现实对齐必须成为持续回路。

本周新增判断

世界模型正在分化为两种运行时：

  • 物理型：外部规律相对稳定，核心是动作条件化、时空一致性和物理准入。
  • 社会经济型：转移规律由主体、市场和制度内生生成，核心是行为校准、经济闭合与反事实有效性。

两者共享状态—动作—转移接口，但不能共享同一套可信度假设。

共同架构正在收敛

1. 世界状态

不仅是像素或 latent，也包括对象、主体私有状态、信念、规则与不确定性。

2. 意图 / 动作

动作必须有语义、时间和可行性合同；World Action Model 把预测和控制接口接在一起。

3. 转移机制

物理动力学、神经生成器、市场清算、制度规则都属于转移层，但约束不同。

4. 评估与准入

从组件指标到世界级轨迹，从相关性到可用于训练、规划、决策或安全证据的等级。

5. 现实对齐

把新观测转成漂移信号，有界更新世界；内部共同演化不能替代外部证据。

跨论文共识与冲突

共识：闭环胜过画质

真正能力来自动作条件下的状态转移、长时一致性和对下游决策的价值，而不是单帧或短视频的视觉逼真。

共识：接口就是研究对象

动作、意图、状态、约束、评估和对齐接口决定系统是否能组合、迁移和审计。

冲突：规律是否固定

物理世界模型默认规律相对稳定；经济世界模型则要求主体和制度共同演化。评估不能简单复用。

冲突：生成与决策的边界

联合模型可能强化未来感知但成本高、难归因；级联模型易治理但误差跨模块传播。

大图景结论：世界模型领域的竞争焦点会从模型规模迁移到“可信世界基础设施”——状态与动作标准、可执行机制、数据闭环、评估准入、现实校准和责任治理。最有价值的系统不是生成最多未来，而是能明确说明哪些未来可用于何种决策、在什么边界下会失效。
