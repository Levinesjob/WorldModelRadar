“能生成世界”与“能承担决策”之间，缺的是运行时证据

本周发生了什么

OpenWorldLib：集成需求被验证

刷新精读核验了 Operator、Synthesis、Reasoning、Representation、Memory 与 Pipeline 骨架。官方仓库约 865 stars、52 forks，并拆出 3D、VLA、simulator 扩展；生态动量真实，但共享 world state 与闭环收益仍未被实验证明。

机器人视频：应用地图完整，证据仍断裂

机器人视频综述覆盖数据生成、动作预测、动力学/奖励、视觉规划和策略评估，却再次暴露视觉指标与真实控制效用之间没有稳定桥梁。

视频基础模型：成本路线分化

视频生成基础综述把隐式记忆、显式 3D 记忆和物理驱动三条 world-model 路线并列。感知一致性接近饱和并不代表 hard-physics 场景已解决。

代码世界模型：环境必须可执行

代码综述将 execution trace、持久状态与 agent interaction 纳入 CWM；但 diffusion、SSM、CWM 缺少统一 benchmark，混合架构主张仍难横向证伪。

本周最重要的连接：机器人需要动作效用，视频模型需要物理与长时一致性，代码模型需要可执行状态，OpenWorldLib 需要共享语义。四条线指向同一个缺口：不是把更多模型接到一个 API，而是证明不同模块围绕同一世界状态做出了更好、更便宜、更可恢复的决策。

哪些假设变弱了

“更多后端就是更强平台”

扩展仓库和统一基类降低接入摩擦，却同步扩大依赖、显存、许可、状态版本和故障面。覆盖率不是平台效用。

“视频 realism 可代理决策价值”

长视频与机器人综述都表明，感知质量可以在物理错误、动作不敏感和策略排序失真时继续上升。

“Memory 容器就是长期状态”

record/select/compress/manage 只是接口起点；没有实体、时间、来源、置信度、冲突与回滚语义，记忆会放大错误。

“统一 API 自然产生协同”

相同调用形状不会自动对齐坐标、动作单位、因果条件和评价目标。协同必须由跨模块任务消融证明。

“大算力结果可直接迁移”

OpenWorldLib 主要在 80GB/141GB GPU 上测试；边缘、实时机器人或多租户服务需要独立的硬件矩阵与预算证据。

“混合架构一定优于单范式”

代码领域的 hybrid thesis 合理，却因 benchmark 分裂而难证伪；多模块的理论互补也可能被编排成本抵消。

机会正在变得更具体

Typed WorldState Registry

管理实体、坐标、事件时间、动作语义、来源、不确定度与版本，使不同生成、推理、3D 和控制后端可安全替换。

World-model observability

把动作敏感度、rollout horizon、漂移、拒答、回退、planner exploitation 和每次有效决策成本纳入 trace。

Use-matched evaluation harness

同一预测分别用于规划、策略评估和数据生成，测任务结果而不是只给生成分数，避免“一模型一榜单”。

Hardware-aware model routing

在 24GB、48GB、80GB、141GB 与边缘设备上建立质量—延迟—显存—能耗前沿，按风险和预算路由后端。

Executable-state benchmark

跨物理、机器人和代码环境测试状态是否可恢复、动作后果是否一致、长时交互是否可回放。

Integration evidence card

要求框架披露新增后端工时、依赖冲突、许可证、端到端回归、故障恢复和迁移成本，把生态热度与系统成熟度分开。

研究空白与可证伪假设

假设如何证伪为什么值得做
共享 WorldState 比仅统一 API 更能提高跨后端复用。固定任务与后端，比较三种集成层级的接入工时、回归率、长期漂移和闭环结果。决定 runtime 平台的护城河究竟是目录、编排还是状态协议。
动作敏感度与物理违例比 FVD 更能预测机器人成功。对多类视频模型做干预测试，比较各指标与真机/高保真仿真成功率的跨模型相关性。建立从生成研究迁移到决策采购的证据桥。
显式 3D memory 能以可接受成本降低长时漂移。固定算力和延迟，对比隐式、显式 3D、混合记忆的状态保持、错误恢复和能耗。判断 3D 表示是基础设施还是昂贵旁路。
模块化 world-model runtime 能降低总拥有成本。把 GPU、数据搬运、环境维护、升级回归、许可治理和人工故障处理全部计入一年期 TCO。验证真实商业需求，阻止把开源关注度误读成付费价值。
物理与代码环境可共享“可执行状态”评测原则。定义跨域最小合同：状态可恢复、动作可复现、后果可核验、失败可归因；检查其预测效度。帮助 taxonomy 从模态命名转向功能与证据命名。
