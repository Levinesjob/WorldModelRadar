领域正在从“一个大模型”转向“分层系统合同”

过去一周最重要的变化不是新收录论文，而是四个长期分散的子领域开始给出同一个答案：机器人、交互视频、医疗和边缘智能都无法靠单一生成器完成闭环。状态、行动、时间、全局约束、本地动力学、评估与拒答必须分层，并通过可版本化接口连接。世界模型的竞争面正在从 backbone 转向系统合同与证据基础设施。

本周发生了什么

机器人：耦合方式成为 taxonomy

机器人学习综述把 world model 与 policy 的关系拆成五类范式，并提醒团队分别评估表示、预测和闭环控制。问题不再只是“是否使用 world model”，而是它在决策路径上承担什么合同。

交互视频：实时性进入核心定义

交互视频综述把 action controllability、长时记忆与实时响应并列为三项硬瓶颈。漂亮的开放环视频不能替代用户输入后的低延迟、可持续状态更新。

通用框架：模块边界先于统一实现

模块化 position反对把任务知识注入称为完整 world model，提出感知、记忆、预测、行动与评估之间的标准化接口是领域形成的前提。

医疗：逼真未来不等于治疗证据

医疗路线图把患者状态、临床动力学和干预支持拆开。观察性 treatment conditioning 可以生成合理病程，却不能自动识别治疗反事实。

边缘：数字孪生与世界模型分层

边缘智能综述给出全局孪生负责事实与约束、本地 world model 负责行动条件预测的迁移图，把通信、能耗和模型同步纳入架构。

Scan：方法密集，领域信号持平

GaussianWAM 与 Game2World 分别暴露空间监督和游戏数据清洗问题，但仍是单项系统。GeoWAM 与 Future Querying 再次出现，也未越过 field-level gate；本周没有新论文进入主表。

本周最重要的连接：机器人 action interface、视频交互延迟、医疗 intervention semantics 和边缘 topology/version，本质上都是同一类缺口：模型之间传递了 tensor，却没有传递可审计的状态、行动、时间、约束和证据语义。

哪些假设变弱了

“一个大 latent 能服务所有决策”

机器人、医疗和边缘场景都显示状态由观察能力、行动空间、目标与时间尺度共同定义。通用表示不等于对每个干预都充分。

“视频质量能代表交互能力”

开放环生成可以隐藏动作不敏感、状态遗忘和响应延迟。交互 world model 必须在输入变化后持续、低延迟地维护可控未来。

“观察性预测能支持干预”

医疗路线图进一步削弱这一假设：病程 plausibility、风险排序与 treatment-conditioned generation 都不是 episode-specific causal evidence。

“世界模型将替代数字孪生”

高保真事实、资产治理和物理验证仍需要孪生；局部 world model 的优势来自舍弃无关细节。两者的职责不同，强行替代会丢失约束或实时性。

“模块化天然降低成本”

模块会增加 schema、版本、时钟、lineage、回放和责任边界。没有标准化合同，拆分只是把模型风险变成集成债务。

“framework 或 taxonomy 等于部署证据”

本周综述提供了有用地图，但跨项目对比口径不同，多个应用仍是概念映射。系统收益必须通过真实闭环与成本预算重新证明。

机会正在变得更具体

State / Action Schema Registry

为机器人、医疗、网络和数字孪生统一管理状态来源、动作语义、时间间隔、约束、版本和不确定性，支持组件替换与审计。

World-model observability

记录 rollout horizon、校准、状态漂移、动作敏感度、拒答、回退和 planner exploitation，把生成系统变成可运营服务。

Digital-twin calibration bridge

把物理边界、稀有场景、topology version 和全局约束选择性下发给本地 world model，同时回收真实偏差用于重校准。

Latency-bounded interactive benchmark

在固定算力、显存和响应预算下，同时测 action fidelity、长时记忆、视频/状态质量和闭环任务结果。

Clinical trajectory evidence layer

把患者状态、干预、剂量、时间、缺失机制、因果假设和多未来校准写入可回放记录，服务影子方案比较而非自主处方。

Edge dynamics federation

针对非 IID 节点共享必要的动力学差异、约束或摘要，优化字节/更新与能量/决策，而不是直接复制通用联邦学习。

研究空白与可证伪假设

假设如何证伪价值
显式 state/action contract 能提高跨模型迁移，而不损害闭环性能。固定数据与算力，替换 encoder、dynamics 或 planner，比较有无标准合同的集成时间、回归率和任务结果。决定模块化平台是否真的可复用。
交互指标能比视频质量更好预测用户或机器人成功率。在统一延迟预算下比较 action sensitivity、memory drift、FVD 与闭环成功率的跨模型相关性。形成可用于采购与研究排序的 benchmark。
数字孪生校准能降低本地 world model 的 OOD 尾部风险。对比纯数据、纯孪生、混合校准三组在未见天气、拓扑和故障下的校准、回退与安全结果。验证分层架构是否值得系统成本。
医疗状态的干预充分性可以用受控历史消融诊断。移除关键治疗、剂量、时间或生理变量，检查 treatment-conditioned rollout 的方向与不确定性是否正确变化。把“患者 latent”从黑箱表征变成可证伪合同。
联邦 latent dynamics 比联邦 policy 更通信高效且稳定。在相同非 IID 节点、掉线率和字节预算下，对比策略、表示与动力学聚合的预测、控制和遗忘。确定 edge world-model 基础设施的核心同步对象。
