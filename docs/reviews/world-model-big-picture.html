领域正在从“会生成”转向“可举证”

本周的关键变化不是模型又变大了，而是世界模型的边界与证据责任同时扩展：经济世界模型把对象从物理规律推进到会因预期而改变的制度系统；决策中心评测则要求每个更强主张都承担更强的干预、闭环与策略证据。

本周发生了什么

反身性环境进入主图

经济世界模型蓝图要求模型同时表示主体信念、制度、清算、共同演化与现实校准。它提示我们：物理世界的误差主要来自动力学近似，经济世界还会因为主体看见模型、改变预期而改变转移规律。

评测从指标表升级为证据合同

决策中心评测立场用 L0–L7 分开生成物、干预、结果、策略排序与优化效用。它把“指标更高”改写为“证据是否足够支持声明用途”。

本周最重要的连接：无论环境由物理规律还是制度与主体共同产生，可信度都不能由表面拟真给出；它取决于模型在声明的干预、时域、策略集合和结果变量上是否保持有效。

Cluster 信号变化

Cluster本周信号判断下一证据
评测、admissibility 与 assurance增强从 L0–L4 的“能否作为模拟证据”继续细化到 L0–L7 的用途分层、策略排序与 exploitability。共享 evaluation card、reset-matched 数据、XGap 实现、跨实验室复现。
领域世界模型增强医疗、边缘智能之后，经济系统暴露出反身性、制度演化与 counterfactual validity 的新约束。封闭经济子系统的可复现实验、行为校准、机制版本与现实对照。
World Action Models持平近期候选仍多是单一架构与训练方法；没有新的 field-level taxonomy 改变主线。统一行动接口、跨身体 contract、闭环 policy ranking 与成本曲线。
通用视频世界模型证据压力上升视觉与 VLM judge 仍有诊断价值，但越来越难单独支撑规划、策略评估或安全主张。行动分支、闭环 occupancy、结果校准、模型优化后的现实收益。

哪些假设变弱了

“视频越真，决策越好”

已有同时报告感知与功能指标的 benchmark 发现排序会分离；潜变量模型也可能没有漂亮解码器却能支持规划。

“一个总分可以代表世界模型”

预测、策略评估、规划、优化、合成数据和表征学习要求不同证据。聚合低层指标会掩盖高层失败。

“更多 Agent 就更像经济”

如果主体没有行为校准、机制没有可执行清算、制度不能审计，规模只会放大叙事与成本，不会自动产生反事实有效性。

“最终成功率能说明模型好坏”

成功率纠缠世界模型、逆动力学、规划器、奖励模型与过滤器；缺少分层消融时不能把结果归因到世界模型。

“固定策略评估足以覆盖优化”

优化器会主动寻找模型的过度乐观区域。L6 策略排序通过，不代表 L7 优化后没有 exploitability gap。

“被动日志天然识别干预”

人类视频、逆动力学恢复动作与隐变量会破坏可识别性；强干预主张需要直接控制的行动分支或可信模拟器。

机会正在变得更具体

World-model evaluation OS

把 decision contract、policy registry、intervention set、run provenance、置信区间与 uncertainty gate 做成基础设施，而不是一次性 benchmark 脚本。

真机最小可行评测

少量 reset-matched tabletop branches、三到五个 anchor policy、低维任务特征与定性 exploitability probe，能填补当前真机论文最明显的证据缺口。

反身性数字孪生治理

经济与组织模拟需要机制 DSL、账本、主体行为校准、制度版本、漂移监测与现实对齐回路；护城河更可能在验证资产而非 Agent 数量。

策略评估即服务

在昂贵或危险部署前，提供可校准的 policy ranking、failure envelope 与拒答，比承诺完整预测现实更可落地。

Action-branch 数据资产

同一历史下不同动作的匹配分支，比更多未标注视频更直接支撑 L4；这可能成为机器人评测的新稀缺数据层。

Benchmark 防投机

隐藏任务、隐藏策略、held-out embodiment 与动态 adversarial policies 将成为评测可信度的基础设施。

研究空白与可证伪假设

假设如何证伪价值
少量 L4 action branches 能预测更高层 policy ranking。跨模型比较 L4 与 L6 的相关性，并在新任务、新身体上验证。决定真机评测能否以低成本替代大量策略 rollout。
XGap 能提前暴露部署中的 planner exploitation。让不同优化器对同一模型进行压力搜索，比较 XGap 与现实失效。可能形成世界模型上线门禁。
行为校准比 Agent 数量更能提高经济模拟外推。固定算力，比较更多 Agent 与更好校准在 held-out 制度冲击下的结果。直接影响经济世界模型的成本结构与产品路线。
用途化 evaluation card 能减少 claim/evidence mismatch。在双盲评审或内部技术评审中比较采用前后的主张收缩、复现率与错误上线率。验证报告标准是否真的改变研究激励。
潜变量 Φ 可跨模型公平比较决策结构。在无共同解码器条件下，用统一任务结果、规划与抽象诊断评测多类 latent model。避免视频输出成为默认且不公平的评测接口。
