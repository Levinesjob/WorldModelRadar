视频生成不是世界模型，除非它能记住、守恒并响应行动

这篇综述用 GAN、Diffusion、Auto-Regressive 与多模态路线重画视频生成史，并把世界模型放在下游终点。它真正提供的判断不是“画质越高越接近世界模型”，而是三项独立合同：长程状态记忆、可检查的空间与物理约束、实时动作响应。现有系统大多仍是短片生成器；视觉一致性接近饱和时，复杂物理成功率仍然很低。

Core thesis & field position

核心观点与领域位置

论文真正说了什么

视频基础模型从隐式对抗学习转向扩散的稳定得分匹配，再转向可与语言推理统一的序列建模。世界模型不是第四种 backbone，而是当视频模型获得记忆、交互、几何和物理合同后出现的系统形态。

改变哪条主线

它把“视频世界模型”拆成隐式长程记忆、显式/隐式 3D 记忆和物理驱动三簇。这让讨论从模型品牌转向状态如何保存、空间如何守恒、动力学如何被约束。

证据边界

论文主体是视频生成综述，世界模型只占一个下游章节；成本表来自异构技术报告，基准也主要测生成质量。它能证明技术依赖关系，却不能证明这些系统已有规划效用或部署安全性。

一句话判断：视频生成是感知与渲染基础设施；只有当状态、行动、转移、约束和决策评估都可查询、可校准时，它才升级为可用世界模型。

Map · Generative evolution

三代生成范式，各自只解决世界模型的一部分

范式训练与表示带来的能力世界模型边界
GAN生成器与判别器做隐式分布匹配，视频侧加入时空联合或运动/内容分解。单步采样快，奠定运动与时序生成。训练不稳定、模式覆盖不足；判别器的“像真”信号不等于因果或物理正确。
Diffusion / DiT在连续 latent 中迭代去噪，以更稳定的监督回归近似数据分布。视觉保真、可控性和开放场景覆盖最强。多步采样延迟高；局部视觉连续不保证对象持久、动作敏感或长程守恒。
Auto-Regressive把视频压缩成离散 token，按链式概率逐 token 生成。可复用 LLM 的长上下文、规划和多模态接口。离散 token 形成信息瓶颈，自回归误差累积，生成成本随序列长度增长。
HybridAR 负责高层计划与状态推进，Diffusion 负责连续细节渲染。有机会分离“想什么”与“画什么”。两套表示与时间尺度需对齐，误差归因、训练稳定性和端到端延迟更复杂。

Deep Read · World-model architecture

从短片生成器到模拟器：三条架构补丁

路线状态 / 转移机制真实问题边界条件与技术债
隐式记忆滑动窗口、稀疏上下文、检索历史帧、RNN/TTT 隐状态。降低流式延迟，延长对象与场景连续性。压缩历史会遗忘；生成误差回流导致结构崩溃；缺少显式 3D 约束。
3D 记忆点云、TSDF、3D Gaussian 等显式地图，或相机感知 token/KV cache。相机移动和重访场景时维持几何与对象持久性。重建与更新有延迟；显式表示会带来伪影，隐式表示又难审计。
物理驱动物理引擎中间态、物理奖励微调，或推理时用 LLM 规划运动。减少穿透、碰撞错误和不守恒等“看似合理”的幻觉。显式引擎覆盖有限，奖励可能被投机，LLM 物理推理也没有守恒保证。
参考架构：multimodal observations → causal tokenizer/state store → action-conditioned transition → geometry/physics constraint → renderer → task evaluator & uncertainty → planner/safety gate → real-world feedback。论文只覆盖其中大半；行动接口、校准和真实反馈仍需工程团队补齐。

Evaluation & falsifiability

视觉分数接近满分，困难物理仍是低成功率

论文给出的信号

多款领先模型在基础时序一致性指标上超过 97%，差异转向语义长尾；但论文汇总的 VideoPhy-2 “Hard”物理场景中，最好模型成功率也只有约 22%。这说明感知稳定与物理可用之间存在断层。

缺失的决策证据

VBench、物理、常识与安全基准仍多在生成输出上评分，没有固定 policy、动作扰动、真实环境 oracle、OOD 拒绝或 planner exploitation 测试，不能直接回答“预测能否支持行动”。

应补的验证

对相邻动作做反事实敏感性测试；测对象/质量/接触守恒；报告随 horizon 的状态漂移；让固定规划器在模型内外运行，比较真实回报、危险漏报、校准与回退率。

可证伪假设

若加入显式 3D 或物理模块后，真实任务成功率、OOD 校准或长程一致性没有超过同算力的视频 baseline，就说明额外结构只是昂贵渲染约束，而非决策所需状态。

Scale, complexity, stability & cost

扩展性、复杂度、稳定性与成本

问题论文证据Radar 判断
可扩展性视频增加时间维度，全球注意力可达 O((HWT)^2)；路线转向因子化/线性注意力、多尺度、序列并行和高压缩 causal VAE。应以单位 GPU 秒的有效、动作敏感 rollout 衡量扩展，而非只看分辨率和时长。
数据高质量密集视频描述稀缺，静态 caption 缺少加速、转向、接触等动态信息；论文建议严格清洗和合成/具身数据。世界模型还需要动作、相机、时间戳、失败与物理属性；普通视频库不能自然补齐这些合同。
成本论文估算三档路径：世界基础模型约 6000–8000 万美元，实验室约 200–300 万美元，精筛商业短视频模型约 20–40 万美元。数字来自不同报告，不能当统一报价；初创团队更适合适配开源 backbone、窄域数据与外部物理/评估层。
稳定性扩散稳定训练但采样慢；AR 易长程误差累积；显式 3D 稳定几何却引入重建伪影和在线更新延迟。必须分别测训练稳定、生成稳定、状态稳定与闭环策略稳定，不能用一个“temporal consistency”代替。

Real problem, fake demand & migration

真实需求、伪需求与迁移路径

真实问题与用户痛点

  • 游戏、机器人、驾驶和 AR/VR 需要低延迟、可交互的场景推进。
  • 长视频需要对象持久、镜头重访和叙事状态，而非逐帧美观。
  • 危险/稀有物理事件数据昂贵，真实测试成本和安全风险高。
  • 团队缺少跨视觉、物理与任务效用的统一评估栈。

伪需求

  • 把 4K、长视频或 prompt adherence 包装成世界理解。
  • 用单次炫酷 demo 声称实时、长期稳定或可规划。
  • 训练通用世界基础模型，却没有独占动作数据和明确任务 oracle。
  • 把生成安全、水印或审美基准误当作部署安全。
阶段迁移动作通过门槛
1. 冻结任务合同定义 observation、action、horizon、latency、约束和真实成功指标。能够区分渲染、状态、动力学和控制失败。
2. 复用基础模型选开源 DiT/AR backbone，只做窄域数据清洗、causal tokenizer 与动作条件。相较无动作视频 baseline 有反事实敏感性。
3. 外挂结构按失效模式加入检索记忆、3D 地图或物理约束，不一次堆齐。同算力下改善真实任务指标，而非只改善画面。
4. 影子规划模型只排序候选；真实/传统模拟器继续给 oracle，记录校准与 planner exploit。危险漏报和 OOD 拒绝达到场景阈值。
5. 受限闭环仅在可撤销动作和安全 envelope 内启用，真实失败持续回流。总成本、延迟和事故率均优于原系统。

Decision

不同读者今天应该做什么

创业者 / 产品负责人

不要正面训练通用视频基础模型。更实际的切口是长程记忆层、3D/物理一致性验证、窄域动作数据运营、模型路由与任务相关评测；价值由减少真机/人工/渲染成本证明。

架构师 / 工程负责人

把 state、transition、renderer、constraint 和 evaluator 拆成可替换服务，版本化时钟、坐标系与动作语义。先测短 horizon 的闭环收益，再扩展分辨率和长度。

研究者 / 战略分析者

关注“高视觉分数为何不转成物理与决策效用”、混合 AR-Diffusion 的状态接口、显式/隐式 3D 成本边界，以及独占时序行动数据是否形成平台护城河。

业务边界：娱乐内容、预可视化和教育视频可接受感知级正确；机器人、驾驶和安全模拟必须达到行动级正确。两者共用 backbone，但验收、责任和成本模型完全不同。

Open questions & Watchlist

开放问题、技术债与 Watchlist

开放问题

  • 何种 state token 能同时支持长程记忆、物理约束与低延迟渲染？
  • 动作敏感性是否比视觉一致性更能预测 planner 收益？
  • 显式 3D 记忆何时胜过检索式帧记忆，其延迟拐点在哪里？
  • 物理奖励会修复动力学，还是只让视频更像 benchmark 偏好？
  • 混合 AR-Diffusion 的误差如何跨高层计划与低层渲染传播？
  • 多少真实行动数据是从“视频模型”跨到“世界模型”的最低门槛？

Watchlist

  • Teng Hu、Jiangning Zhang 团队与 Awesome-Video-Foundations 的分类更新。
  • Genie、Cosmos、Wan/Hunyuan 等系统的动作控制、实时延迟与开放评测。
  • Context-as-Memory、WORLDMEM、TTT-layer 等长程状态方案。
  • 3DGS/TSDF/KV-cache 路线在动态场景中的更新成本和漂移。
  • Physics-IQ、VideoPhy-2 以及加入真实决策 oracle 的后续 benchmark。
  • 内容真实性、水印、数据授权与生成 provenance 标准。
技术债清单：数据许可、去重与 caption 质量；视频/动作时钟；相机内外参；tokenizer 版本；状态缓存失效；3D 坐标系；物理引擎与渲染器差距；随机种子；评估 judge 漂移；安全回退与生成 provenance。
最终判断：这篇论文适合作为视频生成基础设施地图和世界模型候选组件目录，不适合作为“视频生成已经获得世界理解”的证据。最值得追踪的变化，是研究竞争从画质转向记忆、实时交互、3D/物理守恒与任务效用。
